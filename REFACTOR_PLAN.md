# Clean-framework refactor: brief

Branch `clean-framework`. Commit `624965dd` is a snapshot of everything the
analysis really runs on 2026-09-24, including files that were gitignored in
`master`. Goal: a minimal, clean framework to publish on GitHub, with as few
steps as possible from NanoAOD to Combine. Studies are part of it.

## Constraints

- **Do not change physics.** `analysis/`, `corrections/`, `common/prepare_rdf.py`,
  `histograms/hist_maker.py`, the C++ headers and `config/Run3_*/*.yaml` must
  produce identical outputs. Only the orchestration, CLI and layout change.
- There is no AFS, EOS or HTCondor here. Anything that cannot be tested
  without data must be marked in the final report as "to verify on lxplus",
  with the exact command to verify it.
- Keep every change on this branch, in small commits (one topic each). Do not
  touch `master`.

## Target

One entry point, `hmumu <stage> <action>` (extend `tools/hmumu.py`; `./hmumu`
stays the launcher). One implementation per job:

| Stage | Command | Replaces |
|---|---|---|
| skim + corrections | `hmumu skim files/submit/check --era` | `campaigns/run3_skim_v4.sh`, `htcondor/condorsubmit.py skim`, `htcondor/getfiles.py` |
| validation | `hmumu validate --era` | `analysis/scripts/validate.sh`, `run3_dy_weights_skim_v4.sh manifests` |
| DY weights | `hmumu dy-weights run/check --stage jet,ptll,njets` | `campaigns/dy_weights.sh`, `lib/runner.sh`, `campaign_fit()` in `config/campaigns/dy*_skim_v4.sh` (broken: `normalize_era` undefined) |
| histograms | `hmumu hist <campaign> submit/check/hadd/merge-syst/merge-era/finish` | `campaigns/workflow.py` stays the engine; fold in parallel and per-family hadd from `hadd_parallel.py` / `hadd_what_is_ready.py` and file sharding from `tools/shard_hists.py` |
| plots | `hmumu plot <campaign> [--merged]` | `plotting_tools/plot_all_regions.sh` + `hist_plotter.py` |
| combine | `hmumu combine cards/fit --dy-model lnn,rateparam-pu,rateparam-both` | `combine/build_signal_extended_datacards.py`, `combine/run_signal_extended_fits.sh`; `CombineCardWriter` becomes a library (drop its `main()` with hardcoded Aug25 paths) |
| sync | `hmumu sync ...` | `sync/python/*` |
| studies | `studies/<name>/` each with a README and one command | `studies/*.py`, `tools/` study scripts, `campaigns/dnn_studies_skim_v4.sh` |

## Decisions

1. Canonical orchestrator: `campaigns/run3_post_skim_chain.sh`, becomes
   `hmumu chain`. Remove `run3_full_chain.sh` and `finish_and_plot_skim_v4.sh`.
   DY payloads go to `reweights/` as now; DY histograms under
   `<skim>/DY_weights`. (Default, the author can revise it.)
2. Remove the `dnn_vbf_z` and `dnn_vbf_h` campaigns (covered by
   `dnn_vbf_signal` with all regions) and the DY-only `*_dy_sep03` configs.
   Keep the legacy/VBFNet DNN payloads but move them under
   `common/dnn_payloads/legacy/` behind `--dnn-model-set legacy`. (Default,
   the author can revise it.)
3. Studies go on GitHub: `studies/{dnn_binning,dnn_performance,dnn_roc,sensitivity,flashsim,jet_horn,vbf_pair_definition,vbf_cut_optimization,sync_pisa}`.
